Evidence, without the guesswork.

BriefLedger is a lexical document search workbench. It finds source passages; it does not write answers or call an AI provider.

  1. 01

    Keep the source

    Your UTF-8 text is stored in a private SQLite collection for this browser.

  2. 02

    Index small passages

    Overlapping chunks retain their original character offsets and line ranges.

  3. 03

    Match and rank

    SQLite FTS5 matches all search terms, with English stemming. BM25 orders the matching passages.

  4. 04

    Check the evidence

    Read an actual excerpt and open the source. If no passage matches, the result says so.

No account or API key is needed. Your browser cookie grants access to this collection, which expires after seven days. Clearing cookies loses access. This is a demo: use test documents, not sensitive information.
